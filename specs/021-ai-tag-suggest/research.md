# Research: AI 태그 추천 (021-ai-tag-suggest)

**Phase 0** · 2026-10-08 · 입력: [spec.md](./spec.md), [source-notes.md](./source-notes.md), `docs/34-ai-tag-suggest.md`, 013 태그 규칙, 009 금칙어

사용자 지시: 질문 없이 기본값.

## R-1. 판정 순서와 동의 (FR-001~FR-011, FR-021)
- 기능 꺼짐 503 → 로그인 401·인증 전 403 → 자기 글 아님 404(관리자 포함, 휴지통 포함) → 공개 글 아님 400 `AI_PUBLIC_ONLY` → 동의 없음 409 `AI_CONSENT_REQUIRED`(아무것도 보내지 않음) → 정리 후 100자 미만 422 `CONTENT_TOO_SHORT`(횟수 안 셈).
- "공개 글": 화면의 발행 설정 값이 `PUBLIC`이고, 이미 발행된 글이면 DB 공개 범위도 `PUBLIC`(임시글은 발행 때 정하므로 화면 값). 화면도 공개가 아니면 버튼 대신 안내.
- 동의 기록: 34의 `member.ai_consent_at` 제안 대신 V1에 이미 있는 `member_agreement(type='AI', agreed_at)` 행(새 컬럼·마이그레이션 없이 같은 뜻). 철회는 행 삭제. 탈퇴 익명 처리(023)에서 이 행도 지운다.

## R-2. 입력 정리·프롬프트 (FR-012~FR-015)
- `AiInputCleaner`: 코드 블록(언어 + 앞 5줄)을 먼저 빼 두고 이미지 제거·링크 글자만·자동 링크 제거·구분선·제목·인용·목록·강조 기호 제거 → 제목과 합쳐 NFC·공백 하나로. 공급자별 8,000/2,000자로 자르고 잘렸으면 `truncated`.
- 지시문(고정) → 인기 태그(공개 글 기준 상위 50, `ai:tag:popular:{날짜}` 하루, Ollama는 글에 나오는 것만) → 이미 붙인 태그(제외) → 글. 출력 토큰 100, 온도 0.2.

## R-3. 공급자 전환 (FR-016~FR-020, FR-029)
- 순서: Gemini 키가 있고 `exhausted`·`cooldown` 없고 오늘(태평양 시간 기준) 호출 수 < `daily-limit`(450, 넘으면 소진 표시) → Gemini, 아니면 Ollama.
- Gemini 429: 본문의 `quotaId`에 `PerDay` → 다음 초기화까지 소진, `PerMinute` → 60초 쉼, 그 밖 → 60초 쉼 + 같은 날 3번이면 소진. 세 경우 모두 같은 요청을 Ollama로. 시간 초과·5xx → 60초 쉼, 그 요청은 503. 성공 → 오늘 수 +1.
- 두 공급자 모두 JSON 스키마 `{"tags":[string] ≤ 5}`를 강제하고 파싱 실패는 실패. 키는 `x-goog-api-key` 헤더로만(주소·로그에 없음). Ollama 동시 처리 수는 Redis 카운터(여러 서버 공통), 넘으면 503 `AI_BUSY` "잠시 후 다시 시도해 주세요". 시간 제한 10초/30초(JDK HttpClient 읽기 제한).
- 화면은 3초가 지나도 응답이 없으면 "자체 AI로 추천 중이라 조금 걸려요"(Gemini는 10초 안에 끝나므로 길어지면 자체 AI).

## R-4. 재사용 (FR-022~FR-028)
- ① `ai:tag:v{버전}:{SHA-256(정리된 입력)}` 30일(공유) ② `ai:tag:v{버전}:post:{글}` = 지난번 입력·추천·공급자 7일, 3글자 Jaccard ≥ 0.9. 이미 붙인 태그·인기 태그는 판정에 넣지 않고 응답 때 뺀다. [다시 추천]은 ② 건너뜀, ①이 Ollama 결과이고 지금 Gemini를 쓸 수 있으면 다시 만든다. 실패·빈 결과·모두 걸러진 결과는 저장하지 않는다.
- 개인 하루 20회(`ai:tag:user:{회원}:{KST 날짜}`)는 실제 공급자 호출만 센다(실패한 호출 포함).

## R-5. 거르기 (FR-030, FR-031)
- 013 `TagNormalizer.normalize`(소문자·공백→하이픈·허용 문자·30자·금칙어)로 정리, 중복 제거, 이미 붙인 태그 제외, 남은 자리만큼. 0개면 "추천할 태그를 찾지 못했어요".
