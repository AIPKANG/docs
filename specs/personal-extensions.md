# 강성찬 개인 확장 후보 검토 (2026-10-09)

팀은 공통 최소 요구사항(Tier A·B·C, 명세 001~024)만 맞추고, 그 위에 각자 **추가만** 하기로 했다(01 §2-4, 01 원칙 2: 개인 확장을 켜도 공통 완료 기준은 그대로 지킨다).
아래는 팀 문서(docs/)에 강성찬 몫으로 적힌 것을 모은 목록이다. **원본 "블로그 플랫폼 요구사항 명세서"(64개 기능)는 이 저장소에 없어서**, 문서에 이름만 있고 내용이 없는 항목은 "정의 필요"로 두었다.

규칙: 새 기능은 새 모듈 패키지(02: `group/`·`mission/`·`streak/` 등) + 새 마이그레이션(V2 이후)으로 넣고, 공통 테이블은 CHECK 교체 같은 최소 변경만 한다(03 E-10). Spec Kit 순서로 `specs/025-…`부터.

## 추천 순서

1 친구 공개 → 4 공개 전환(응원 알림) → 11 조회수 기준 → 2 링크 공개 → 3 그룹 공개 → 5 답글 깊이 → 6 잔디·스트릭 → 7 통계. 8·9·10·12는 정의를 받은 뒤.
1이 2·3·4의 바탕이고, 이미 규격(06 §6)과 테이블이 있어 바로 명세로 옮길 수 있다.

## 넣을 때 지킬 것

- 친구·그룹·링크 글은 홈·태그·검색·트렌딩·피드·sitemap에 절대 안 나온다(06 §7 "새는 곳을 없앤다"). 공통 목록 조건은 그대로 `PUBLIC`만.
- 탈퇴 정리 단계에 친구·그룹 삭제를 끼운다(13 §3-3, 팔로우 앞).
- 신고·숨김·권한 표(42)에 새 공개 범위 칸을 더하고 테스트한다.
- 52 ERD 검토 A-1(`friendship` 삭제 제안)은 1을 하면 "유지"로 정리된다.

## 4차 (10-12) — chan 요청으로 더한 것

- **058 글쓰기 서식 창**: 노션 선택 메뉴처럼 글을 고르면 창이 뜬다 — 서식 종류, 글자 색·배경색, 밑줄, 서식 지우기(저장은 그대로 Markdown)
- **059 AI로 글 다듬기**: 서식 창에서 고른 글을 AI가 다듬기·맞춤법·짧게·쉽게·직접 부탁대로 고쳐 제안
- **060 보이는 대로 쓰기**: 서식 창을 누르면 Markdown 표시 대신 바로 서식이 보이는 본문 칸(저장은 Markdown, Markdown으로 쓰기 전환)
- **061 화면 테마를 개인 설정으로**: 머리말의 다크 모드 버튼을 설정 화면 "화면 테마"(시스템·라이트·다크)로 옮김(024 FR-004를 이 서비스에서 바꿈)
- **062 빈 임시글이 안 생기게**: 아무것도 안 쓰고 떠나면 바로 지우고, [새 글]은 남은 빈 글을 다시 열고, 내 글 관리에서 빈 임시글을 뺌
- **063 내 글은 발행 글 먼저, 설정은 섹션 메뉴로**: 내 글 관리 기본 탭·탭 순서를 발행 글 먼저로, 설정을 7개 섹션으로 묶어 옆 메뉴에서 골라 봄

- **065 표 넣기**: 글쓰기 [표] 버튼과 `/표`, 칸 사이 Tab·Enter 이동(저장은 GFM 표)

## 6차 (10-13) — chan 15개 목록(역할 스레드로 나눠 작업)

- **067 화면 정리**: 내 글·시리즈 글 카드형, 홈 바로가기 카드 빼기, 카드 목록 무한 스크롤, 꼬리말 꽃 장식 빼기, 첫 배너 사진 미리 받기·사진 1년 보관
- **068 기능 다듬기**: 알림 창을 열면 모두 읽음, 피드를 추천 블로그·팔로잉 블로그 글로 나눔, AI 태그 추천 최소 20자, [발행] 설정을 팝업으로
- **069 친한 친구**: 친구를 서로 요청·수락하던 방식(025)에서, 내가 팔로우하는 사람 중에서 골라 넣는 한쪽 관계(인스타 "친한 친구")로. 기존 맞친구는 양쪽 친구로 옮김
- **070 가입 화면 덜어내기**: 로그인과 같은 그림 카드, 비밀번호 규칙은 칸을 누르면 보임, 주소 안내 한 줄, 약관 "모두 동의"
- **071 릴리스 노트 화면**: `/releases`가 CHANGELOG.md를 보여 주고 꼬리말에 링크
- **073 비공개 계정**: 인스타처럼 팔로우는 요청, 수락한 팔로워만 글을 봄. 수락 안 된 사람에게는 프로필 윗부분만, 홈·검색 등 공용 목록에서는 빠짐
- **074 인스타식 계정**: 이메일 → 6자리 코드 가입(소셜 버튼도 같은 카드), 이메일·아이디 로그인, 코드로 비밀번호 찾기, 아이디(블로그 주소) 14일에 두 번 변경·옛 주소 넘김, 별명 14일에 두 번, 블로그 위쪽 인스타식 숫자 줄
- **076 주소에서 @ 빼기**: 블로그 주소를 `/아이디`로, 예전 `/@아이디` 주소는 301로 넘김, 사이트 맨 앞 경로는 아이디로 못 씀
- **081 피드에 추천 글 섞기**: 팔로우한 글 4개마다 추천 글 1개(이유 표시), 팔로우한 글이 끝나면 추천 글로 이어 감, 팔로우가 없으면 처음부터 추천
