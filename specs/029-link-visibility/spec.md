# Feature Specification: 링크 공개 (LINK)

**Feature Branch**: `029-link-visibility` | **Created**: 2026-10-09 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (01 §2-4 "링크 공개", 03 E-3 `visibility`에 `LINK`). 공통 완료 기준(001~024)은 그대로 지킨다.

## User Scenarios & Testing

### User Story 1 - 주소를 아는 사람에게만 보여 주기 (P1)

글쓴이는 공개 범위에서 "링크 공개"를 고른다. 글 화면에 공유 주소(`…/posts/번호?key=열쇠`)가 보이고, 이 주소를 아는 사람은 로그인하지 않아도 읽을 수 있다. 주소가 없으면 없는 글과 같은 404다.

1. **Given** 링크 공개 글, **When** 열쇠가 맞는 주소로 연다, **Then** 비회원도 읽는다(검색 엔진에는 noindex).
2. **Given** 같은 글, **When** 열쇠 없이·틀린 열쇠로 연다, **Then** 404 "볼 수 없는 글이에요".
3. **Given** 링크로 연 사람, **When** 글 화면에서 좋아요·댓글을 한다, **Then** 공개 글과 같은 규칙으로 된다(같은 화면에서 보낸 요청).
4. **Given** 링크 공개 글, **When** 홈·블로그·태그·검색·트렌딩·피드·sitemap을 본다, **Then** 어디에도 없다.

### User Story 2 - 링크 다시 만들기 (P2)

글쓴이는 [새 링크 만들기]로 열쇠를 바꾼다. 예전 주소로는 바로 읽을 수 없다. 글쓴이만 할 수 있다.

## Requirements

- **FR-001**: 공개 범위 값에 `LINK`를 더한다(공통 값과 규칙은 그대로).
- **FR-002**: 열쇠는 글마다 하나, 추측할 수 없는 값(24바이트 난수)이며 다시 만들면 예전 값은 무효다.
- **FR-003**: 공용 목록 조건은 공개 글만 그대로라 링크 공개 글은 어떤 목록에도 나오지 않는다.
- **FR-004**: 설정 `blog.share.link.enabled=false`면 링크 공개를 고를 수 없다(400).
- **FR-005**: 기본 공개 범위(설정)에는 링크 공개를 두지 않는다(글마다 고르는 값).

## Success Criteria

- **SC-001**: 열쇠 없는 요청이 링크 공개 글을 읽는 경우 0건.
- **SC-002**: 새 링크 직후 예전 주소 요청은 모두 404.

## Assumptions

- 조회수는 공개 글만 센다(공통 규칙 그대로) — 링크로 읽은 것은 세지 않는다.
- 링크 공개 → 전체 공개로 바꾸면 그때가 최초 공개(026 확인 창 적용).
