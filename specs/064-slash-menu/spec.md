# Feature Specification: 글쓰기 / 명령

**Feature Branch**: `064-slash-menu` | **Created**: 2026-10-13 | **Status**: Implemented (1.17.0)

**Scope**: **강성찬 개인 확장** (10-13 chan 남은 일 6번 "글쓰기 `/` 명령"). 노션처럼 줄 처음에 `/`를 쓰면 넣을 것을 고르는 창이 뜬다. 저장은 그대로 Markdown이라 004(자동 저장)·007(렌더링)은 그대로다. 058 서식 창·060 보이는 대로 쓰기 칸 위에 더한다.

## User Scenarios & Testing
### User Story 1 - / 로 블록 고르기 (P1)
본문 줄(문단) 처음에 `/`를 쓰면 커서 아래에 창이 뜬다: 본문 · 제목 · 소제목 · 글머리 목록 · 번호 목록 · 할 일 목록 · 인용 · 코드 블록 · 표 · 구분선 · 사진. 글자를 더 쓰면 걸러지고(`/목` → 목록 세 가지, `/표`, `/h2`, `/table`), ↑↓로 고르고 Enter·Tab 또는 눌러서 넣는다. 고르면 `/검색어`는 지워지고 그 줄이 그 서식이 된다(표·구분선은 그 자리에 넣고, 사진은 사진 고르기 창을 연다). Esc로 닫으면 그 `/` 줄을 벗어날 때까지 다시 뜨지 않는다.

### User Story 2 - Markdown으로 쓰기에서도 (P2)
Markdown 칸에서도 같은 창이 뜨고, 고르면 줄 앞 표시(`## `, `- `, `1. `, `- [ ] `, `> `)를 달거나 ``` 로 감싸거나 표·`---`를 빈 줄로 띄운 제 줄에 넣는다.

## Requirements
- **FR-001** `/`는 줄(문단) 처음일 때만 창을 띄운다. `/` 뒤 검색어는 공백·`/` 없이 12자까지(`/usr/bin` 같은 글은 맞는 것이 없어 닫힌다). 목록·제목·표·코드 안에서는 띄우지 않는다.
- **FR-002** 검색어는 이름(한글)과 영어 낱말의 앞부분으로 찾는다. 맞는 것이 없으면 닫는다.
- **FR-003** 한글 입력 중 Enter는 조합을 끝내며 줄을 나누려 하므로, 창이 떠 있으면 그 줄 나누기를 막고 고른 것을 넣는다.
- **FR-004** 창의 줄을 눌러도 본문 커서는 그대로다. 다른 곳을 누르거나 칸을 떠나면 닫힌다. 모양은 058 서식 창과 같고 화면 밖으로 넘치지 않는다(아래 자리가 없으면 위).
- **FR-005** 구분선은 앞 줄과 빈 줄로 띄운다(`---`가 위 글을 제목으로 만들지 않게).

## Success Criteria
- 자체 검사(`node frontend/src/test/js/format-toolbar.test.mjs`)에 / 명령 4개(찾기·줄 앞 표시·코드 블록·표와 구분선) 통과, 글쓰기 화면에 안내 문구(EditorPageIT).
- 로컬 브라우저: 보이는 대로 쓰기·Markdown 두 칸에서 `/제`·`/목`·`/표`·`/구분`·`/사진`, ↑↓·Enter·Esc 확인.
