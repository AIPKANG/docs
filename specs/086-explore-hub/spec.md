# Feature Specification: 추천은 탐색 한곳에(피드·홈 정리)

**Feature Branch**: `086-explore-hub` | **Created**: 2026-10-14 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-14 chan "추천 블로그랑 피드랑 분리 작업도 해줘, 차라리 피드에 있는 형식을 탐색에 써서 하나로 합쳐줘", 겹치는 화면 점검 1~5 "추천해 주는 대로 다 만들어줘"). 081의 피드 섞기를 되돌린다.

## 무엇이 어디로
| 전 | 후 |
| --- | --- |
| 피드: 추천 블로그 줄 + 팔로우 글 사이 추천 글(081) | 피드: 팔로우한 사람 글만. 목록 끝 "탐색에서 새 글을 찾아보세요 [탐색]" |
| 홈: [최신 글]·[트렌딩] 탭 | 홈: 최신 글 하나. `/?tab=trending` → `/explore?tab=trending` |
| 홈 오른쪽 칸: 추천 글·추천 블로그·인기 태그 | 홈 오른쪽 칸: "둘러보기" 상자(탐색에서 더 보기·태그 전체 보기) + 사이트 링크 |
| 홈 목록 위: 새로 온 작가 | 탐색 [추천] 첫 화면 |
| 인기 태그 4곳(검색 창·홈·탐색·/tags) | 검색 창·/tags만(탐색은 "태그 전체 보기" 링크) |
| 탐색: 인기 태그·새 작가·추천 글 목록·추천 블로그 상자 | 탐색: [추천]·[트렌딩] 탭. [추천] = 추천 블로그 줄(팔로우 버튼) + 새로 온 작가 줄 + 추천 글 카드 무한 스크롤 |
| 검색 결과·미션 "모두의 오늘 글" 자체 카드 | 공용 글 카드(fragments/post-card) |

## Requirements
- **FR-001** 탐색 추천 글: 077 규칙 순서, 내 글·팔로우한 사람 글(피드에 나옴)·볼 수 없는 글 제외, 앞 100개, 12개씩(`/api/explore?cursor=위치`). 비회원도 본다.
- **FR-002** 탐색 트렌딩: 019 그대로(스냅샷 커서, 끝나면 최신 글로 이어짐, `/api/posts/trending`).
- **FR-003** 미션 글 중 공용 목록 카드가 없는 글(비공개 계정 등)은 예전 미션 카드로.

## Success Criteria
- ExploreIT, FollowIT, TrendingIT, NewcomerIT, FriendIT 갱신 통과(FeedMixIT 삭제).

## 알려진 한계
- 실제 사이트의 로그인 화면은 테스트로만 확인했다.
