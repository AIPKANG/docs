# Feature Specification: 화면 정리 (카드형 목록·무한 스크롤·홈/꼬리말 정리·배너 사진 빨리)

**Feature Branch**: `067-screen-tidy` | **Created**: 2026-10-13 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-13 chan 목록 6·8·9·11·14번: "내 글도 카드형식으로 변경 가독성을 위함", "홈화면 최신글, 트렌딩 등 겹치는 요소 존재, 하나로 줄이기", "블로그 내리면 더보기 형식, 무한 스크롤로 제작", "맨 아래 배너 크기 너무 커서 꽃들은 삭제, 심플하게 여백 조정", "처음 배너 고양이 나오는 거 너무 늦게 나오는데 애초에 처음부터 나오게"). 화면과 정적 파일 보관만 바꾸고 기능·주소·API·DB는 그대로.

## User Scenarios & Testing
### User Story 1 - 내 글을 카드로 본다 (P1)
내 글 관리(발행 글·임시글·휴지통)와 시리즈 글 목록이 한 줄 나열 대신 카드로 보인다. 시리즈는 카드에 "1편, 2편" 순서가 붙는다.

### User Story 2 - 홈에 같은 길이 두 번 나오지 않는다 (P1)
배너 아래 바로가기 카드(인기 글/최신 글/관심 태그)를 빼고 최신 글·트렌딩 탭만 둔다.

### User Story 3 - 내리면 다음 글이 저절로 붙는다 (P1)
카드 목록(홈·태그·검색·블로그·피드) 끝이 화면에 가까워지면 다음 묶음을 불러온다. [더 보기] 버튼은 그대로 둔다.

### User Story 4 - 꼬리말이 가볍다 (P2)
꼬리말 아래 언덕·꽃 장식을 빼고 한 줄로, 위아래 여백을 줄인다.

### User Story 5 - 첫 배너 사진이 빨리 뜨고, 다음부터는 바로 뜬다 (P1)
홈 배너 사진을 css보다 먼저 받기 시작하고, 사진은 브라우저가 오래 보관한다.

## Requirements
- **FR-001** 내 글 관리 `#post-rows`와 시리즈 글 `.series-cards`를 카드 격자(auto-fill, 최소 260px/240px)로. 마크업·manage.js 동작은 그대로(관리자 화면 목록은 대상 아님).
- **FR-002** 홈 `.home-quick` 바로가기 카드와 그 css를 지운다.
- **FR-003** list-more.js: `.list-more`가 화면 아래 400px 안에 들어오면 다음 묶음을 부른다(IntersectionObserver). 불러오는 중에는 다시 부르지 않고, 실패하면 저절로 다시 부르지 않는다([다시 시도]로만). 붙인 뒤에도 끝이 화면 안이면 이어서 부른다. 지원하지 않는 브라우저는 버튼만.
- **FR-004** 꼬리말 `.footer-garden`(SVG)과 css를 지우고 `.footer-inner` 위아래 여백 28px → 18px.
- **FR-005** `/images/**`도 css·js처럼 주소에 내용 지문을 붙이고 1년 `immutable` 보관(StaticCacheConfig). 템플릿의 사진 주소는 `@{...}`로, css 안 `url()`은 Spring이 같은 지문 주소로 바꾼다. 홈 첫 화면은 배너 사진을 `<link rel="preload" as="image" fetchpriority="high">`로 먼저 받는다.

- **FR-006** (후속, 10-13) 배너 사진을 hero.jpg(230KB)에서 같은 크기 hero.webp(72KB, WebP 품질 80)로 바꾼다. 원본과 1:1로 잘라 비교해 차이가 보이지 않을 것.
- **FR-007** (후속, 10-13) 홈 탭 줄에서 인기 태그 3개를 빼고 최신 글·트렌딩만 둔다. 인기 태그는 오른쪽 인기 태그 상자(태그 수·아이콘) 하나로.

## Success Criteria
- 로컬에서 홈 배너 사진 주소에 지문이 붙고 `Cache-Control: max-age=31536000, public, immutable`, preload 주소와 css 안 주소가 같다.
- 홈에 바로가기 카드가 없고 꼬리말은 한 줄.
- 가짜 API로 무한 스크롤이 저절로 부르고, 실패 뒤 멈추고, [다시 시도] 뒤 이어진다.
- 배너 사진이 `image/webp` 72KB로 내려가고 1년 보관된다. 홈 탭 줄에 태그가 없다.
- CI `test` 통과.

## 남은 것
- `og-default.png`(글 공유 미리보기)는 바깥에서 쓰는 절대 주소라 지문 없이 1년 보관된다. 바꿀 일이 생기면 파일 이름을 바꾼다.
- 내 글 관리는 무한 스크롤 대상이 아니다(쪽 넘김 그대로).
