# 화면 전체 점검 (2026-10-08)

로컬(개발 프로필, compose)에서 실제 브라우저로 사용자 흐름을 한 바퀴 돌았다. 계정 4개(작성자·독자·신고자·관리자)를 만들어 확인.

## 확인한 흐름
| 흐름 | 결과 |
|---|---|
| 이메일 가입 → 인증 메일(Mailpit) → 인증 완료 | 정상 |
| 설정(프로필·계정·알림·AI 동의·탈퇴 진입) | 정상(칸 이름 배치 고침) |
| 글쓰기: 자동 저장 "✓ 저장됨", 미리보기(코드 블록·목록·`<script>`는 글자로), 태그 칩, 발행 | 정상(태그 칸 크기 고침) |
| AI 태그 추천: 동의 창 → 동의 → 공급자 없음 → "지금은 추천할 수 없어요" | 정상(글쓰기 영향 없음) |
| 다른 계정의 댓글·좋아요·팔로우 → 종 아이콘 3 → 펼침 목록 문장·묶음("외 1명") | 정상 |
| 신고 → 신고자 본인인 관리자는 처리 불가(400) → 다른 관리자 숨기기 → 작성자에게 안내·알림 | 정상(작성자의 댓글 칸 고침) |
| 독자 탈퇴 신청 → 그 댓글 "탈퇴한 사용자의 댓글이에요", 좋아요 수 유지 | 정상 |
| 휴대폰 크기(375px)·다크 모드: 상세·설정 | 정상(머리말은 세 줄로 접힘) |
| 사진 올리기 | 브라우저 파일 선택은 도구 한계로 API로 확인(서명 업로드·완료·글에 표시) |

## 고친 것
1. 가입 화면 블로그 주소 앞부분이 `devlog.com/@`로 고정돼 있던 것 → 실제 사이트 주소(`APP_BASE_URL`)로 표시
2. 설정·가입 화면의 글자 칸 이름이 칸 옆에 붙어 어색하던 것 → 칸 위에
3. 발행 설정의 태그 입력 칸이 제목 칸 모양(큰 글씨·밑줄)을 물려받던 것 → 제목 칸에만 적용
4. 관리자가 숨긴 글에서 작성자에게 댓글 칸이 보이지만 쓰면 실패하던 것 → "숨겨진 글에는 댓글을 쓸 수 없어요" 안내
5. 테마 전환 버튼이 메뉴 밖에 따로 있어 좁은 화면에서 혼자 한 줄을 차지하던 것 → 메뉴 맨 끝으로

## 이어서 고친 것
- 좁은 화면(640px 이하)에서 머리말이 세 줄로 접히던 것 → 한 줄(블로그·검색·🔔·테마·☰), 나머지 메뉴는 ☰ 안으로. 스크립트가 없으면 예전처럼 모두 펼쳐 보인다. Esc·바깥 누르기로 닫힌다.
