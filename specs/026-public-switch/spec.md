## User Scenarios & Testing *(mandatory)*

### User Story 1 - 공개로 바꾸기 전에 확인 (Priority: P1)

글쓴이가 나만 보기·친구 공개 글을 전체 공개로 바꾸려 하면, 바로 바뀌지 않고 "모든 사람이 볼 수 있게 돼요"를 확인한 뒤에 바뀐다.

**Why this priority**: 실수로 누른 한 번에 개인적인 글이 모두에게 드러나는 것을 막는다(요구사항 점검 10-09에서 빠진 것으로 확인).

**Independent Test**: 내 글 관리와 글 상세에서 비공개 글을 전체 공개로 고른 뒤 [취소]하면 그대로이고, [공개하기]를 눌러야 바뀌는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 나만 보기 또는 친구 공개 글, **When** 내 글 관리나 글 상세에서 공개 범위를 "전체 공개"로 고른다, **Then** "모든 사람이 볼 수 있게 돼요. 공개할까요? [공개하기] [취소]"가 뜬다.
2. **Given** 확인 창, **When** [취소]를 누른다, **Then** 공개 범위가 원래 값으로 돌아오고 서버에는 아무것도 바뀌지 않는다.
3. **Given** 확인 창, **When** [공개하기]를 누른다, **Then** 전체 공개가 되고 "공개했어요"가 잠깐 보인다.
4. **Given** 전체 공개 → 나만 보기·친구 공개처럼 좁히는 방향, **When** 바꾼다, **Then** 확인 없이 바로 바뀐다.
5. **Given** 스크립트가 꺼진 화면, **When** 공개 범위를 바꾼다, **Then** 확인 화면(페이지)을 거쳐 바뀐다.

---

### User Story 2 - 처음 공개되면 홈 맨 위에 (Priority: P1)

나만 보기나 친구 공개로 두었던 글을 처음으로 전체 공개하면, 그 순간이 최초 공개 시각이 되어 홈·태그 목록의 맨 위에 새 글처럼 나온다. 이미 한 번 공개된 적이 있는 글을 다시 공개하면 원래 자리로 돌아간다.

**Acceptance Scenarios**:

1. **Given** 한 달 전에 친구 공개로 발행한 글, **When** 오늘 처음 전체 공개로 바꾼다, **Then** 홈 최신 글 맨 위에 나오고 카드 날짜는 오늘이다.
2. **Given** 공개했다가 비공개로 돌렸던 글, **When** 다시 공개한다, **Then** 최초 공개 시각은 그대로라 처음 공개된 자리에 나온다.
3. **Given** 처음 공개, **When** 팔로워가 있다, **Then** 팔로워에게 기존 "새 글" 알림이 간다(017 그대로, 다시 공개할 때는 안 간다).

---

### User Story 3 - 첫 공개 응원 알림 (Priority: P2)

친구 공개였던 글이 처음 전체 공개되면, 그 글을 먼저 볼 수 있었던 글쓴이의 친구들에게 "OO님이 친구에게만 보여 주던 글을 모두에게 공개했어요"라는 응원 알림이 간다.

**Acceptance Scenarios**:

1. **Given** 친구 3명이 있는 B의 친구 공개 글, **When** B가 처음 전체 공개한다, **Then** 친구 3명에게 응원 알림이 하나씩 가고, 누르면 그 글로 간다.
2. **Given** 친구이면서 팔로워인 사람, **When** 같은 글이 처음 공개된다, **Then** 알림은 하나만 받는다(응원 알림이 새 글 알림을 대신한다).
3. **Given** 나만 보기였던 글, **When** 처음 공개된다, **Then** 응원 알림은 없다(친구가 미리 본 글이 아니므로). 팔로워 새 글 알림만 간다.
4. **Given** 알림 설정에서 "새 글" 알림을 끈 친구, **When** 응원 알림이 생긴다, **Then** 받지 않는다(같은 설정을 따른다).

### Edge Cases

- 확인 창이 떠 있는 사이 다른 탭에서 이미 공개했다면 [공개하기]는 아무것도 바꾸지 않고 성공으로 끝난다.
- 숨김 처리된 글은 공개로 바꿔도 목록에 나오지 않는다(공통 숨김 규칙 그대로).
- 응원 알림은 탈퇴 유예·정지된 친구에게 보내지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 공개 범위를 넓히는 변경(나만 보기·친구 공개 → 전체 공개)은 확인을 거쳐야 한다(MUST). 좁히는 변경은 확인 없이 바로 된다.
- **FR-002**: 처음 전체 공개되는 순간을 최초 공개 시각으로 남겨야 하며 이후 다시 바뀌지 않아야 한다(MUST, 공통 005·006 규칙 재확인).
- **FR-003**: 친구 공개 → 전체 공개가 처음 일어나면 글쓴이의 친구에게 응원 알림을 보내야 한다(MUST). 같은 사람에게 같은 글로 새 글 알림과 겹치지 않아야 한다(MUST).
- **FR-004**: 응원 알림은 "새 글" 알림 설정을 따른다(MUST).
- **FR-005**: 공통 완료 기준(001~024)은 그대로 통과해야 한다(MUST).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 확인 없이 넓어지는 공개 범위 변경은 0건이다(내 글 관리·글 상세 두 곳 모두).
- **SC-002**: 친구·팔로워가 겹치는 사람이 받는 알림은 글마다 1건이다.
- **SC-003**: 처음 공개된 글은 다음 홈 요청에서 맨 위에 보인다.

## Assumptions

- 응원 알림 문구와 "새 글 알림을 대신한다"는 기본값으로 정했다. 문구는 나중에 바꿀 수 있다.
- 025(친구 공개)가 먼저 들어가야 User Story 3이 의미가 있다. User Story 1·2는 지금 공통 범위(나만 보기)에도 바로 쓸 수 있다.
