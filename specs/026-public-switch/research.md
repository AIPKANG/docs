# Research: 공개 전환 — 강성찬 개인 확장

- **R-1 확인 방식**: 브라우저 기본 확인 창(`window.confirm`). 휴지통·변경 취소가 이미 같은 방식을 쓴다.
- **R-2 응원 대상**: 친구 공개였던 글만(친구가 미리 볼 수 있었던 글). 나만 보기 → 전체 공개는 팔로워 새 글 알림만(017 그대로).
- **R-3 겹침**: 친구이면서 팔로워면 응원 1건만. 응원을 먼저 만들고 새 글 알림 쿼리에서 같은 글의 응원을 받은 사람을 뺀다(한 디스패치 안에서 순서대로).
- **R-4 설정**: 별도 끄기 없이 "새 글" 끄기를 따른다(spec FR-004). 알림 끄기 표(`notification_mute`)는 바꾸지 않는다.
