# Research: 답글 무제한 깊이 — 강성찬 개인 확장

- **R-1 펼치기**: 답글 더 보기 API 대신 `<details>`로 접어 둔다(페이지에 이미 다 읽어 온 나무를 보여 주기만 하면 되고, 스크립트 없이도 된다).
- **R-2 기존 데이터**: 1단계 구조로 달린 답글(`@닉네임에게`가 있는 것)은 그대로 보이고, 새 답글부터 바로 위 댓글 아래에 달린다.
- **R-3 탈퇴 정리 위험**: 공통 정리 단계는 "답글은 행 삭제"였는데, 깊이 모드에서는 탈퇴자의 답글 아래 남의 답글이 FK `ON DELETE CASCADE`로 함께 지워진다. 잎만 지우고 자리는 남기도록 바꿨다(공통 1단계에서도 결과 같음).
- **R-4 Thymeleaf 재귀 조각**: 조각 매개변수 이름이 바깥 반복 변수와 같으면 값이 가려져 아래 단계가 비었다 → 조각마다 다른 이름(item·n·level·nodeLevel)을 쓴다.
