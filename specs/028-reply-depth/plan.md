# Implementation Plan: 답글 무제한 깊이 — 강성찬 개인 확장

**Spec**: [spec.md](./spec.md) | **Date**: 2026-10-09

공통 스키마(`parent_id` 자기참조) 그대로. 설정값 `blog.comment.max-depth`(공통 1, 0 = 무제한)으로 켠다. 운영 설정(application.yml)은 0, 공통 댓글 테스트는 1로 돈다.

- **쓰기**(`CommentService.create`): 깊이 모드면 답글을 바로 위 댓글 아래에 단다(`reply_to_member_id` 없음, 답글 알림은 바로 위 작성자). 한도가 2 이상이면 깊이를 검사.
- **삭제**: 깊이와 상관없이 같은 규칙으로 정리 — 아래 답글이 있으면 자리만, 없으면 행 삭제 후 위로 올라가며 빈 자리 정리. 공통 1단계에서도 결과가 같다.
- **탈퇴 정리**: 같은 규칙(행을 지우면 남의 아래 답글이 함께 지워지므로 잎만 지우고, 빈 자리는 위로 올라가며 정리).
- **읽기**(`CommentQuery`): 깊이 모드면 페이지의 최상위 20개 아래 대화 전체를 재귀 쿼리 1번으로 읽어 나무로(페이지당 최대 2,000개). 특정 댓글로 들어오면 그 대화의 최상위가 있는 페이지.
- **화면**: `fragments/comment.html`의 `thread`·`node` 재귀 조각. 3단계까지 펼치고 4단계부터 `<details>` "답글 N개 더보기", 각 단계 처음 3개 + 나머지 접기. 스크립트 없이 동작, 특정 댓글로 오면 접힌 곳을 펼쳐 보여 줌. 들여쓰기는 3단계 폭까지만.
