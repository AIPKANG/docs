# Feature Specification: 미션 배지

**Feature Branch**: `066-mission-badges` | **Created**: 2026-10-13 | **Status**: Implemented (1.17.0)

**Scope**: **강성찬 개인 확장** (10-13 chan 남은 일 6번 "미션 배지", 057에서 "배지는 나중에"로 미뤄 둔 것). 057 오늘의 미션 기록(완료한 날 수·최고 연속 일수)으로 배지를 정한다. 표·마이그레이션 없음.

## User Scenarios & Testing
### User Story 1 - 내 배지 보기 (P1)
로그인한 사람은 미션 화면 "내 기록" 밑 "🏅 내 배지"에서 받은 배지 수(예: 2 / 7)와 배지 7개를 본다. 받은 배지는 색으로, 아직인 배지는 흐리게 받는 법과 함께 보인다.

| 배지 | 받는 법 |
|---|---|
| 🌱 첫 미션 | 미션을 처음 완료 |
| 🔥 3일 연속 | 최고 연속 3일 |
| 🌿 미션 10번 | 완료한 날 10일 |
| ⭐ 일주일 연속 | 최고 연속 7일 |
| 🌳 미션 30번 | 완료한 날 30일 |
| 👑 한 달 연속 | 최고 연속 30일 |
| 🏆 미션 100번 | 완료한 날 100일 |

## Requirements
- **FR-001** 배지는 따로 저장하지 않고 화면을 열 때 057 기록(그날 안에 발행했고 지금도 발행 중인 미션 글의 날)으로 정한다. 그래서 미션 글을 지우거나 내리면 배지가 빠질 수 있다.
- **FR-002** 배지는 본인만 본다(로그인 안 한 사람·다른 사람에게는 칸이 없다). 블로그 첫 화면에 보이면 친구 공개·나만 보기 미션 글의 수가 드러나므로 넣지 않는다.

## Success Criteria
- DailyMissionIT: 배지 기준(기록 → 받은 배지), 미션을 한 번 완료하면 "1 / 7"·첫 미션·받는 법이 보이고, 로그인 안 한 사람에게는 배지 칸이 없다.
