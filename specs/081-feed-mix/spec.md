# Feature Specification: 피드에 추천 글 섞기

**Feature Branch**: `081-feed-mix` | **Created**: 2026-10-13 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-13 chan: "피드에는 추천하는 글이랑 팔로우한 계정글 섞어서 띄어주는 형식으로 바꿔줘").

## 확인한 것(바꾸기 전)
- 탭은 없었다. 위에 "추천 블로그"(068, 블로그 줄), 아래 "팔로잉 블로그 글"(팔로우한 사람 글만). 추천 글은 피드에 없었다.

## 결정(인스타그램 방식)
- 하나의 목록: 팔로우한 글 최신순, **4개마다 추천 글 1개**. 추천 카드 머리에 "추천 · 이유"(관심 태그와 같은 글 / 많이 읽는 글).
- 팔로우한 글이 끝나면 "팔로우한 글을 모두 봤어요" 줄 뒤에 추천 글로 무한 스크롤이 이어진다. 팔로우가 없으면 처음부터 추천 글.
- 추천은 077 규칙(내 관심 태그와 같은 새 사람 글 → 최근 7일 조회수), 내 글·팔로우한 사람 글(따로 나옴)·볼 수 없는 글은 뺀다. 이미 보인 글은 화면이 건너뛴다.
- "추천 블로그" 줄(068)은 그대로 위에 둔다.
- 커서: `추천위치.팔로우커서`(팔로우 글이 끝나면 `-`). 잘못된 커서는 처음부터.

## Requirements
- **FR-001** `/feed`, `/api/feed`가 섞인 목록. API는 `items`, `nextCursor`, `reasons`(추천 글 번호 → 이유), `dividerBefore`.
- **FR-002** 추천은 앞 100개까지(그 뒤는 "모든 글을 다 봤어요").

## Success Criteria
- FeedMixIT: 팔로우 없음 → 추천만, 팔로우 5개 → 4개·추천·1개·추천들, "모두 봤어요" 줄, 내 글 없음.
- FollowIT: 팔로우 글과 추천 글이 겹치지 않고, 비공개·휴지통·임시 글은 나오지 않음.

## 알려진 한계
- 추천 순서가 조회수로 바뀌면 다음 묶음에서 한두 개를 건너뛰거나 다시 볼 수 있다(화면이 이미 본 글은 건너뜀).
- 로그인한 실제 화면은 로컬 계정이 없어 테스트로만 확인했다.
