# Feature Specification: 화면 테마를 개인 설정으로

**Feature Branch**: `061-theme-setting` | **Created**: 2026-10-12 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-12 chan 요청 "다크모드 지금 메인에 있는데 개인 설정으로 넣어줘"). 공통 024(다크 모드)의 테마 고르기를 머리말 버튼에서 설정 화면으로 옮긴다. 이 개인 서비스에서는 024 FR-004(모든 페이지 머리말 맨 오른쪽 버튼)를 이 명세로 바꾸고, 나머지 024 요구(그리기 전 적용·기기별 저장·인라인 스크립트 없음·색 역할)는 그대로 지킨다.

## User Scenarios & Testing
### User Story 1 - 설정에서 테마 고르기 (P1)
로그인한 사람은 설정 → "화면 테마"에서 시스템 설정 / 라이트 / 다크 중 하나를 고른다. 고르면 바로 화면에 반영되고, 이 기기 브라우저에 저장돼 다른 페이지·새로 고침·로그아웃 뒤에도 유지된다.

## Requirements
- **FR-001** 머리말에는 테마 버튼이 없다. 설정 화면에 "화면 테마" 칸(라디오 3개, 지금 테마가 골라진 상태)을 둔다.
- **FR-002** 저장·적용 방식은 024 그대로: 브라우저 저장소 `blog-theme`(시스템이면 지움), 그리기 전 `theme-init.js`가 적용, "시스템"은 기기 설정 변경을 새로 고침 없이 따른다.
- **FR-003** 스크립트가 없으면 "화면 테마" 칸을 숨긴다(024 FR-011과 같은 이유). 로그인하지 않은 방문자는 기기 설정(시스템)을 따른다.

## Success Criteria
- ThemeIT: 모든 페이지 머리말에 테마 버튼이 없고, 설정 화면에 숨긴 "화면 테마" 칸(시스템·라이트·다크)과 스크립트가 실린다. 나머지 024 검사(그리기 전 적용·인라인 스크립트 없음·색 역할) 통과.
