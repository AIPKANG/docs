# Feature Specification: 인스타식 계정 (가입·로그인·아이디·별명·프로필)

**Feature Branch**: `074-insta-account` | **Created**: 2026-10-13 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-13 chan 요청 "인스타그램을 따라가자, 이메일 가입부터 모든 것 다", 카드에서 '계정·소셜' 선택). 홈·피드 화면, 스토리, DM, 블로그 글쓰기·읽기 화면은 범위 밖. 세부 기본값은 인스타 방식으로 정함(아래 결정).

## 결정
- **이메일 가입**: 이메일 → [인증 코드 받기] → 메일로 온 6자리 코드 확인 → 별명·아이디·비밀번호 → 약관 동의. 코드로 확인한 이메일은 인증된 계정으로 만들고 인증 링크 메일을 보내지 않으며, 가입 뒤 바로 홈으로 간다. 같은 가입 카드 아래에 Google·GitHub로 계속하기 버튼.
  - 코드는 10분 유효, 5번 틀리면 지워진다. 보내기 한도: 이메일당 1분 1회·하루 10회, IP당 1시간 20회. 이미 가입된 이메일이면 보내지 않고 알린다(기존 가입 화면도 같은 정보를 알려 줌).
  - 스크립트 없이 코드 없이 가입하면 예전처럼 미인증 계정 + 인증 링크 메일(미인증 제한도 그대로).
- **로그인**: 이메일 또는 아이디(블로그 주소)와 비밀번호. `@`가 없으면 아이디로 찾는다. 잠금(5번 실패 15분)·IP 한도는 기존 그대로.
- **비밀번호 찾기**: 메일에 6자리 코드(10분)와 기존 링크(30분)를 함께 보낸다. 요청 뒤 같은 화면에서 코드 + 새 비밀번호를 넣는다. 화면은 가입 여부와 상관없이 같다.
- **아이디(블로그 주소) 변경**: 설정 > 프로필에서. 14일에 두 번까지. 소셜 가입자도 접두어(`go-`·`gi-`) 없이 아무 아이디나 고른다(접두어는 가입 때 이메일·소셜 주소를 나누는 용도일 뿐, 로그인은 로그인 수단 표로 구분). 접두어를 붙이면 자기 가입 수단 것만(예전 주소로 되돌리기). 검사는 가입과 같다. 예전 아이디는 14일 동안 본인만 되돌릴 수 있고, `/@옛아이디/...`로 오면 새 주소로 302(하위 경로·쿼리 유지). 다른 사람이 그 아이디를 가져가거나 주인이 탈퇴하면 넘김이 끝난다.
- **별명 변경**: 30일에 한 번 → 14일에 두 번.
- **블로그 첫 화면 위쪽**: 사진·별명·@아이디·소개 아래에 "게시물 N · 팔로워 N · 팔로잉 N" 굵은 숫자 줄, 다른 사람이면 팔로우 버튼, 내 블로그면 [프로필 편집].
- **모으지 않는 개인정보**: 생일·전화번호·이름(실명)은 넣지 않았다.
- **끄기 스위치** `blog.insta-account.enabled`(기본 켬). 끄면 링크 방식 가입·비밀번호 찾기, 이메일 로그인만, 주소 변경 불가, 별명 30일에 한 번, 예전 머리말. 이미 바꾼 옛 주소 넘김은 계속된다.

## Requirements
- **FR-001** V18: `handle_history(old_handle PK, member_id, changed_at, hold_until)`, `member.nickname_prev_changed_at`.
- **FR-002** `EmailCodeService`: Redis `auth:code:{용도}:{이메일 해시}`에 코드 해시·값·틀린 횟수(원문 이메일·코드 없음), 새 코드는 이전 코드를 덮는다.
- **FR-003** `POST /api/signup/code`, `POST /api/signup/code/verify`(세션에 확인한 이메일), `POST /signup`은 같은 이메일이면 인증된 채로 가입.
- **FR-004** `LocalUserDetailsService`: `@` 없는 값은 활성 회원 주소 → LOCAL 로그인 수단.
- **FR-005** `POST /password/reset-code`(이메일·코드·새 비밀번호). 정책 위반이면 코드를 쓰지 않는다.
- **FR-006** `PUT /api/me/handle` → `HandleChangeService`(공통 규칙에서 주소를 바꾸는 유일한 경로). `HandleService`는 남이 잡아 둔 옛 주소를 중복으로 본다(대안 주소 후보에서도 뺌).
- **FR-007** `OldHandleRedirectFilter`: `/@옛주소` GET·HEAD → 지금 주소로 302.
- **FR-008** `NicknameChangeService`: 켜져 있으면 그 전 변경이 14일 밖일 때만 바꿀 수 있다.

## Success Criteria
- InstaAccountIT: 코드 가입(인증됨·링크 메일 없음·1분 한도·틀린 코드), 5번 틀리면 코드 없어짐·가입된 이메일 거절, 아이디·이메일 로그인, 코드 비밀번호 찾기(재사용 불가), 주소 변경·옛 주소 넘김·잡아 둠·되돌리기·14일 두 번·기간 뒤 남이 가져가면 넘김 끝·접두어 고정, 별명 14일 두 번.
- 공통 규칙 테스트(닉네임 30일, 주소 불변 소스 검사)는 스위치를 끈 상태·`HandleChangeService` 예외로 계속 통과.

## 알려진 한계
- 주소 변경 횟수는 옛 주소 한 줄당 하나로 센다. 같은 옛 주소를 14일 안에 다시 떠나면 한 번으로 센다.
- 글 본문·댓글에 적힌 예전 주소 링크는 바꾸지 않는다(넘김으로 열림).
- 가입 코드 단계는 스크립트가 있어야 보인다.
