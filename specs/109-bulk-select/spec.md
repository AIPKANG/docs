# Feature Specification: 내 글 여러 개 골라 한 번에

**Feature Branch**: `109-bulk-select` | **Created**: 2026-10-16 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-16 chan "내 글에서 글 한번에 여러개 선택할 수 있게도 만들어줘 한번에 삭제하거나 이런 용도로").

## 바꾸기 전
- 내 글(발행 글·임시글·휴지통)은 글마다 ⋯ 메뉴로 하나씩만 지우거나(휴지통으로)·복구·영구 삭제·공개 범위를 바꿀 수 있었다.

## 결정
- 줄마다 체크 칸, 목록 위에 [전체 선택]과 "N개 선택됨". 하나라도 고르면 동작 버튼이 보인다.
- 발행 글 탭: [공개 범위 바꾸기 ▾](전체·친구·링크·그룹 공개·나만 보기), [휴지통으로]. 임시글 탭: [휴지통으로].
- 휴지통 탭: [복원], [영구 삭제].
- 지우는 것은 바로 지우지 않고 휴지통으로(30일 뒤 자동 삭제, 복원 가능). 휴지통으로·영구 삭제는 확인 창을 한 번 거친다. 넓히는 공개 범위(→ 전체 공개)도 확인(026 규칙).
- 새 서버 API는 없다. 글마다 쓰던 API(휴지통으로 DELETE, 복원 POST, 영구 삭제 DELETE, 공개 범위 PATCH)를 고른 글마다 차례로 부르고, 된 줄은 목록에서 빼거나(휴지통·복원·영구 삭제) 표시를 바꾼다. 실패한 줄은 그 줄 아래 이유, 끝나면 "N개를 휴지통으로 옮겼어요" 같은 알림 상자와 탭 옆 글 수 갱신.
- 스크립트가 꺼져 있으면 체크 칸과 선택 줄은 보이지 않는다(글마다 ⋯ 메뉴는 그대로).
- 고르는 범위는 화면에 불러온 글까지(더 보기로 붙인 글 포함).

## Success Criteria
- 발행 글 탭에서 둘을 골라 공개 범위 → 나만 보기: 두 글만 PATCH, 두 줄의 공개 범위 표시가 바뀌고 알림. 이어 [휴지통으로]: 두 글만 DELETE, 두 줄이 빠지고 글 수 갱신.
- 휴지통 탭 [전체 선택] → [영구 삭제]: 확인 뒤 모든 줄 permanent DELETE.
- PC·휴대폰에서 선택 줄이 목록 위에 붙어 있고, 기존 ⋯ 메뉴·필터·탭은 그대로.
