# Feature Specification: 아이디를 주 이름으로

**Feature Branch**: `082-handle-as-name` | **Created**: 2026-10-13 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-13 chan "지금 글쓰면 별명이 메인인데 인스타처럼 아이디가 메인이게 만들수있나?").

## 결정
- 인스타그램처럼 사람을 가리키는 이름은 아이디(@ 없이). 닉네임은 블로그 첫 화면 프로필 줄과 사람 목록에서 아이디 아래 작게만(077 모양 그대로).
- 바뀐 곳: 글 상세 작성자 줄·브라우저 제목, 모든 카드(홈·탐색·피드·태그·검색·내 글·추천 글·관심 있을 만한 글, 서버 화면과 무한 스크롤 둘 다), 댓글·답글("@아이디에게")·방명록, 알림 문구("아이디님이 …"), 새로 온 작가·추천 블로그 줄, 화면 제목(블로그·짧은 기록·시리즈·방명록·팔로워/팔로잉·블로그 안 검색), 프로필 메뉴의 "아이디의 블로그", 미션 글 줄, RSS 채널 제목과 글 작성자.
- 그대로: 관리자 화면(아이디와 닉네임 둘 다), 설정의 닉네임 칸, 프로필 아이콘 첫 글자(닉네임 첫 글자), 메일(이름을 쓰지 않음), 공유 미리보기(OG)는 글 제목·요약만 써서 바꿀 것 없음.
- 탈퇴한 사람은 그대로 "탈퇴한 사용자".

## Requirements
- **FR-001** `AuthorDisplay.shortLabel()`은 아이디(탈퇴면 "탈퇴한 사용자"). 알림 문구가 이것을 쓴다.
- **FR-002** 템플릿·스크립트에서 이름으로 보여 주던 `nickname`은 `handle`로.

## Success Criteria
- AuthorFragmentIT·AuthorDisplayTest·NotificationIT가 아이디 기준으로 통과, 전체 테스트 통과.
