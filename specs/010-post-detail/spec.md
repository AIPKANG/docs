## User Scenarios & Testing *(mandatory)*

### User Story 1 - 공개 글 읽기 (Priority: P1)

독자(비회원 포함)는 `/@블로그주소/posts/{번호}`에서 공개·발행된 글을 읽는다. 제목, `닉네임 @블로그주소` 작성자 영역, 목록 카드와 같은 날짜, 다시 발행했다면 "수정됨" 표시, 정화된 본문, 태그, 좋아요·조회 수, 작성자 카드, 댓글이 보인다.

**Why this priority**: C-READ-2(Tier A)의 기본 흐름이며 서비스의 핵심 가치(글 읽기)다.

**Independent Test**: 공개 글 하나를 비회원으로 열어 화면 구성 요소와 날짜·수정됨 표시, 메타 정보를 확인한다.

**Acceptance Scenarios**:

1. **Given** 발행된 `PUBLIC` 글, **When** 비회원이 상세를 열면, **Then** 제목(페이지의 유일한 1단계 제목), 작성자 사진·`닉네임 @블로그주소`, 날짜, 본문, 태그, 좋아요 수, 조회 수, 작성자 카드, 댓글 수와 첫 댓글들이 보인다.
2. **Given** 공개 글, **When** 날짜를 보면, **Then** 목록 카드와 같은 처음 공개된 시각이 같은 형식(24시간 이내 "N시간 전", 이후 `2026.10.02`)으로 보인다.
3. **Given** 다시 발행한 글, **When** 상세를 보면, **Then** "수정됨 · 10월 3일"이 보이고, 공개 범위만 바꾼 글에는 보이지 않는다.
4. **Given** 태그가 붙은 글, **When** 상세를 보면, **Then** 태그가 입력한 순서대로 `#이름`으로 보이고 각각 태그별 목록으로 연결된다.
5. **Given** 공개 글, **When** 링크 미리보기·검색 엔진이 가져가면, **Then** 정규 주소, 제목, 요약 앞 160자, 첫 이미지 원본(없으면 서비스 기본 이미지), 공개 시각, (있을 때) 수정 시각이 제공된다.
6. **Given** 작성자 영역, **When** 누르면, **Then** 그 사람의 블로그 `/@블로그주소`로 이동한다.
7. **Given** 본문에 GIF가 있는 글, **When** 열면, **Then** 첫 장면 + ▶로 보이고 누르면 재생된다.
8. **Given** 코드 블록이 있는 글, **When** 열면, **Then** 코드 강조가 적용되고, 코드 블록이 없는 글에서는 코드 강조 기능을 불러오지 않는다.

### User Story 2 - 볼 수 없는 글은 없는 글과 똑같은 404 (Priority: P1)

없는 글, 남의 비공개·임시 글, 휴지통 글, 숨긴 글(남이 볼 때), 탈퇴 유예 작성자의 글은 모두 404이며 상태 코드·본문·링크 미리보기 문구가 같다. 볼 수 있는 글을 다른 블로그 주소로 열면 올바른 주소로 안내되지만, 볼 수 없는 글은 같은 상황에서도 404다.

**Why this priority**: C-READ-2 완료 기준 그 자체이며 존재 은닉(헌법 III)을 지킨다.

**Independent Test**: 권한 매트릭스(42 §5-1)의 모든 칸을 통합 테스트로 확인하고, 각 404 응답을 없는 글 응답과 비교한다.

**Acceptance Scenarios**:

1. **Given** 없는 글 번호, 남의 `PRIVATE` 글, 남의 임시글, 휴지통 글, 숨긴 글(남이 볼 때), 탈퇴 유예 작성자의 글, **When** 열면, **Then** 모두 404이고 상태 코드·본문·미리보기 문구("볼 수 없는 글이에요")·검색 엔진 비수집 지시가 같다.
2. **Given** 볼 수 있는 글을 다른 사람의 블로그 주소로 연 경우(`/@other/posts/42`), **When** 열면, **Then** 올바른 주소 `/@author/posts/42`로 영구 이동(301)한다.
3. **Given** 볼 수 없는 글을 다른 사람의 블로그 주소로 연 경우, **When** 열면, **Then** 이동 없이 404다(작성자가 누구인지 드러나지 않는다).
4. **Given** 블로그 주소에 대문자가 섞인 주소, **When** 열면, **Then** 소문자 주소로 301 이동한다.
5. **Given** 글 번호 자리에 숫자가 아닌 값, **When** 열면, **Then** 404다.
6. **Given** 관리자, **When** 남의 `PRIVATE` 글이나 임시글을 열면, **Then** 404다.
7. **Given** 작성자 본인, **When** 자기 휴지통 글을 열면, **Then** 404다(휴지통 목록에서만 보임).

### User Story 3 - 작성자가 자기 글을 볼 때 (Priority: P1)

작성자는 상세에서 자기 글의 상태(임시저장/비공개/수정 중/숨김) 배지와 [수정]·[공개 범위]·[삭제] 버튼을 본다. 임시글 주소를 열면 에디터로, 수정 중인 글을 열면 독자와 같은 마지막 발행본과 "수정 중" 안내를 본다.

**Why this priority**: C-OWN-1·C-POST-3과 연결된 작성자 흐름이며, 두 겹 권한(화면 숨김 + 서버 검사)의 화면 쪽이다.

**Independent Test**: 같은 글을 작성자·다른 회원·비회원으로 열어 버튼 노출 차이를 확인하고, 작성자로 임시글·수정 중 글·비공개 글·숨긴 글을 열어 상태별 화면을 확인한다.

**Acceptance Scenarios**:

1. **Given** 작성자 본인의 임시글, **When** 그 글의 상세 주소를 열면, **Then** 에디터(이어 쓰기)로 임시 이동(302)한다.
2. **Given** 수정 중인 작업본이 있는 발행 글, **When** 작성자가 상세를 열면, **Then** 독자와 같은 마지막 발행본과 함께 상단에 "수정 중인 내용이 있어요(10월 3일 14:03 저장) [이어서 수정] [변경 취소]"가 보인다.
3. **Given** 작성자의 발행 `PRIVATE` 글, **When** 작성자가 열면, **Then** 🔒 배지와 "나만 볼 수 있는 글이에요"가 보이고 날짜는 발행 시각이다.
4. **Given** 관리자가 숨긴 자기 글, **When** 작성자가 열면, **Then** "운영 정책에 따라 숨겨진 글이에요. 다른 사람에게는 보이지 않아요"가 보인다.
5. **Given** 자기 글, **When** 작성자가 보면, **Then** [수정]·[공개 범위 ▾]·[삭제]가 보이고 [좋아요]·[신고]·[팔로우]는 보이지 않으며 좋아요 수만 보인다.
6. **Given** 남의 글, **When** 인증된 회원이 보면, **Then** [좋아요]·[신고]·[팔로우]가 보이고 [수정]·[공개 범위]·[삭제]는 보이지 않는다.
7. **Given** 비회원, **When** 상세를 보면, **Then** 좋아요 수만 보이고, [팔로우]를 누르면 로그인 화면으로 간다.
8. **Given** [공개 범위 ▾], **When** 작성자가 `PUBLIC`/`PRIVATE`를 고르면, **Then** 다시 발행 없이 즉시 바뀐다.
9. **Given** [삭제], **When** 작성자가 누르면, **Then** 휴지통 이동 확인 창이 뜬다.

### User Story 4 - 조회 수는 실제로 본 경우만 센다 (Priority: P2)

상세를 연 것만으로는 조회 수가 오르지 않는다. 독자의 화면에 글이 1초 이상 보인 뒤에 따로 기록 요청이 가며, 작성자 본인이 보는 상세에는 기록 기능이 들어가지 않는다. 기록이 실패해도 상세 화면은 영향을 받지 않는다.

**Why this priority**: 조회 수(Tier B)의 정확도와, 부가 기능이 핵심(읽기)을 막지 않는다는 원칙(헌법 V)을 지킨다. 세부 판정은 조회수 명세가 맡는다.

**Independent Test**: 상세를 요청만 하고 조회 수가 바뀌지 않는지, 작성자 상세 화면에 기록 기능이 없는지, 기록 요청을 실패시켜도 상세가 정상인지 확인한다.

**Acceptance Scenarios**:

1. **Given** 공개 글, **When** 상세를 요청만 하면(화면 표시 1초 미만 또는 스크립트 없음), **Then** 조회 수가 바뀌지 않는다.
2. **Given** 독자의 화면에 글이 1초 이상 보임, **When** 기록 요청이 가면, **Then** 조회수 기능의 제외·중복 규칙에 따라 기록된다.
3. **Given** 작성자 본인, **When** 자기 글 상세를 열면, **Then** 화면에 조회 기록 기능이 포함되지 않는다.
4. **Given** 조회 기록 실패, **When** 상세를 보면, **Then** 상세는 정상으로 보이고, 화면의 조회 수는 저장된 값을 그대로 보여준다(1만 이상은 `1.2만`).

---

### User Story 5 - 댓글로 바로 가기와 첫 댓글 표시 (Priority: P2)

독자는 상세에서 댓글 수와 첫 댓글 20개(각 답글 처음 3개 포함)를 바로 본다. 알림 링크(`?comment={번호}`)로 들어오면 그 댓글이 보이는 위치부터 댓글 영역이 그려진다.

**Why this priority**: 댓글(Tier B)과 알림(Tier C)이 상세에 붙는 자리다. 규칙 상세는 각 기능 명세가 맡는다.

**Independent Test**: 댓글 30개가 있는 글의 상세 응답에 첫 20개가 포함됐는지, `?comment=25`로 열면 25번 댓글이 보이는지, 정규 주소에 `?comment`가 없는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 댓글 30개가 있는 글, **When** 상세를 열면, **Then** 머리말에 "댓글 30"과 최상위 첫 20개(각 답글 처음 3개 포함)가 처음 응답에 들어 있고 [댓글 더 보기]가 있다.
2. **Given** 알림 링크 `?comment={번호}#comment-{번호}`, **When** 열면, **Then** 그 댓글이 보이는 위치부터 댓글 영역이 그려진다.
3. **Given** `?comment=` 또는 `?utm_source=` 같은 쿼리가 붙은 주소, **When** 정규 주소를 확인하면, **Then** 쿼리가 없는 주소다.

---

### Edge Cases

- 볼 수 있는지 판정을 주소 블로그 비교보다 먼저 한다. 그래서 볼 수 없는 글에 301을 주는 일이 없다.
- 작성자 본인이 보는 비공개 글에도 검색 엔진 비수집 지시가 붙는다.
- 상세 응답은 보는 사람마다 내용(좋아요 여부, 작성자 버튼)이 다르므로 공유 캐시에 저장되지 않는다. `PUBLIC`이 아닌 글은 저장 금지까지 붙는다.
- 작성자 카드의 소개는 글자만, 줄바꿈을 유지해 보인다.
- 사진이 없는 작성자는 기본 아이콘으로 보인다.
- 탈퇴 유예 회원 본인은 복구 화면만 본다.
- 조회 기록·GIF 재생 모두 인라인 스크립트 없이 동작해야 한다(브라우저 보안 정책).
- 스크립트가 꺼진 독자는 조회 수에 세지 않는다.
- 관리자가 신고 처리로 연 상세가 조회 수에 섞이는지는 아직 정해지지 않았다(FR-021).

## Requirements *(mandatory)*

### Functional Requirements

**주소와 판정**

- **FR-001**: 글 상세 주소는 `/@블로그주소/posts/{글 번호}`여야 MUST 한다(번호 기반). (C-READ-2)
- **FR-002**: 상세 요청은 ① 블로그 주소에 대문자가 있으면 소문자 주소로 301 → ② 글 번호가 숫자가 아니면 404 → ③ 글을 볼 수 있는지 판정(볼 수 없으면 404) → ④ 주소의 블로그가 작성자와 다르면 올바른 주소로 301 → ⑤ 작성자 본인의 임시글이면 에디터로 302 → ⑥ 상세 표시 순서로 MUST 처리되어야 한다. (C-READ-2, C-OWN-1)
- **FR-003**: 볼 수 있는지 판정은 공개 범위 명세(006)의 단일 접근 정책을 MUST 사용하고, 판정 순서는 권한 매트릭스(42 §3)를 따른다. (C-READ-2, C-POST-4)
- **FR-004**: 없는 글, 남의 비공개·임시 글, 휴지통 글(작성자 포함), 숨긴 글(작성자 외), 탈퇴 유예 작성자의 글은 404이며, 상태 코드·본문·링크 미리보기 문구가 모두 MUST 같아야 한다. 관리자도 남의 비공개·임시 글은 404다. (C-READ-2)
- **FR-005**: 정규 주소에는 쿼리 문자열을 MUST NOT 넣어야 하고 정규 주소를 페이지에 명시해야 한다. `?comment`만 댓글 영역에 넘긴다.

**화면 구성**

- **FR-006**: 제목은 페이지의 유일한 1단계 제목이어야 MUST 하며 글자로만 표시한다(본문 제목은 2단계부터). (C-READ-2, C-POST-1)
- **FR-007**: 작성자 영역은 프로필 사진(없으면 기본 아이콘)과 `닉네임 @블로그주소`를 MUST 함께 보여야 하고, 누르면 그 블로그로 이동해야 한다. (C-AUTH-2)
- **FR-008**: 표시 날짜는 공개 글이면 처음 공개된 시각(목록 카드와 같은 값·형식), 작성자가 보는 비공개 글이면 발행 시각이어야 MUST 한다. 기계가 읽을 수 있는 원래 시각도 함께 넣는다.
- **FR-009**: "수정됨 · 날짜"는 다시 발행으로 수정 시각이 기록된 글에만 MUST 보이고, 공개 범위만 바꾼 글에는 MUST NOT 보여야 한다. (C-POST-3, C-POST-4)
- **FR-010**: 본문은 발행 때 저장된 정화된 HTML을 그대로 MUST 출력해야 하며 조회 때 다시 렌더링하지 않는다. 코드 블록이 있을 때만 코드 강조 기능을 불러온다. (C-POST-1)
- **FR-011**: 태그는 입력 순서대로 `#이름`으로 표시하고 각각 인코딩된 태그 이름의 태그별 목록 주소로 MUST 연결해야 한다. (C-TAG-1)
- **FR-012**: 태그 아래 반응 줄에 좋아요 수와 "조회 N"(1만 이상 `1.2만` 형식)을 MUST 보여야 한다. 내가 좋아요를 눌렀는지는 상세를 가져올 때 함께 알아야 한다. 조회 수는 목록 카드에는 없다. (C-LIKE-1, C-VIEW-1)
- **FR-013**: 작성자 카드에 작성자 사진·닉네임·블로그 주소·소개(글자만, 줄바꿈 유지)·[블로그 가기]·[팔로우]를 MUST 보여야 한다. 내 글이면 [팔로우]가 없고, 비회원이 [팔로우]를 누르면 로그인 화면으로 간다.
- **FR-014**: 상세 처음 응답에 댓글 수와 최상위 첫 20개 댓글(각 답글 처음 3개 포함)을 MUST 포함해야 하고, `?comment={번호}`로 들어오면 그 댓글이 보이는 위치부터 댓글 영역을 그려야 한다. (C-CMT-1)
- **FR-015**: 본문의 GIF는 첫 장면 + ▶로 보이고 누르면 재생되도록 MUST 상세 페이지에 재생 기능을 포함해야 한다. (C-IMG-1)

**작성자·행위자별 표시 (화면 쪽 권한)**

- **FR-016**: [수정]·[공개 범위 ▾](`PUBLIC`/`PRIVATE` 즉시 변경)·[삭제](휴지통 이동 확인 창)는 작성자에게만 MUST 보여야 한다. (C-OWN-1)
- **FR-017**: [좋아요]·[신고] 버튼은 인증된 회원·관리자이고 작성자가 아닐 때만 MUST 보여야 하며, 그 외에는 좋아요 수만 보인다. 서버 쪽 판정은 각 기능 명세와 권한 매트릭스가 다시 검사한다. (C-OWN-1, C-LIKE-1)
- **FR-018**: 상태 배지(임시저장 / 🔒 비공개 / 수정 중)는 작성자에게만 MUST 보여야 한다.
- **FR-019**: 작성자가 수정 중인 글을 열면 독자와 같은 마지막 발행본과 "수정 중인 내용이 있어요(저장 시각) [이어서 수정] [변경 취소]" 안내를 MUST 보여야 한다. 작업본 미리보기는 에디터에서 한다. (C-POST-3)
- **FR-020**: 관리자가 숨긴 글을 작성자가 열면 "운영 정책에 따라 숨겨진 글이에요. 다른 사람에게는 보이지 않아요"를 MUST 보여야 한다(세부는 신고·숨김 명세, Tier C).

**조회 기록**

- **FR-021**: 상세 조회 자체는 조회 수를 MUST NOT 바꿔야 한다. 독자가 보는 공개·발행 글 상세에는 글이 화면에 1초 이상 보이면 한 번 기록 요청을 보내는 기능을 넣고, 작성자 본인에게는 넣지 않는다. 제외·중복 판정은 조회수 명세에서 한 곳에서 한다. 관리자(신고 처리로 연 조회)의 조회도 기록하지 않는다 (clarify 2026-10-07, 사용자 확정). (C-VIEW-1)
- **FR-022**: 조회 기록의 실패가 상세 응답에 영향을 MUST NOT 주어야 하며, 화면의 조회 수는 저장된 값을 그대로 보여준다(이번 방문의 +1을 기다리지 않음).
- **FR-023**: 조회 기록·GIF 재생을 포함해 상세 페이지는 인라인 스크립트 없이 MUST 동작해야 한다(글 번호 등 필요한 값은 화면 요소의 데이터로 넘긴다). (C-POST-1)

**링크 미리보기·검색 엔진·캐시**

- **FR-024**: 공개 글은 페이지 제목 "{제목} - {닉네임}", 설명(요약 앞 160자), 정규 주소, 글 유형, 미리보기 제목·설명, 미리보기 이미지(본문 첫 이미지 원본, 없으면 서비스 기본 이미지), 공개 시각, (있을 때) 수정 시각을 MUST 제공해야 하며 값은 속성 이스케이프한다.
- **FR-025**: 비공개·임시·볼 수 없는 글은 공통 미리보기 문구와 검색 엔진 비수집 지시를 MUST 써야 한다. 작성자 본인이 보는 비공개 글에도 비수집 지시를 붙인다. (C-POST-4)
- **FR-026**: 모든 상세 응답은 공유 캐시 금지(개인용·재검증) 지시를 MUST 붙여야 하고, `PUBLIC`이 아닌 글은 저장 금지까지 붙인다.

**성능**

- **FR-027**: 상세 한 번에 데이터 조회는 최대 5번(글+작성자, 태그, 내 좋아요 여부, 내 팔로우 여부, 작성자일 때 작업본 유무) + 첫 댓글 조회로 MUST 제한되어야 하며, Markdown 원문은 읽지 않는다. 조회 기록은 상세 응답 경로에서 하지 않는다.

### Key Entities *(include if feature involves data)*

- **글 상세 보기**: 글 번호, 제목, 정화된 본문, 상태·공개 범위, 처음 공개 시각, 발행 시각, 수정 시각, 요약, 좋아요 수, 조회 수, 댓글 수, 작업본 유무(작성자에게만), 숨김 여부.
- **작성자 정보**: 블로그 주소, 닉네임, 프로필 사진, 소개.
- **보는 사람 관점 정보**: 내가 좋아요를 눌렀는지, 내가 작성자를 팔로우 중인지, 내가 작성자인지.
- **링크 미리보기 정보**: 정규 주소, 미리보기 제목·설명·이미지, 공개·수정 시각, 또는 공통 404 문구.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 권한 매트릭스(42 §5-1)의 모든 칸에 대한 통합 테스트가 통과하고, 볼 수 없는 글과 없는 글의 응답 차이가 0건이다.
- **SC-002**: 볼 수 있는 글을 잘못된 블로그 주소로 열었을 때 100% 올바른 주소로 이동하고, 볼 수 없는 글은 같은 상황에서 100% 404다.
- **SC-003**: 글 1만 건 기준 상세 서버 응답이 300ms 이내이고, 상세 한 번의 데이터 조회가 최대 5번 + 첫 댓글 조회를 넘지 않는다.
- **SC-004**: 상세 요청만으로 조회 수가 바뀌는 경우가 0건이고, 작성자 본인의 상세 화면에 조회 기록 기능이 포함되는 경우가 0건이다.
- **SC-005**: 상세 페이지의 인라인 스크립트가 0개다.
- **SC-006**: 작성자 전용 버튼이 작성자 외에게, [좋아요]·[신고]·[팔로우]가 작성자 본인에게 보이는 경우가 0건이다.
- **SC-007**: 공개 글 100%에 정규 주소·미리보기 정보가 있고, 그 밖의 경우 100%가 공통 문구와 비수집 지시를 쓴다.
- **SC-008**: 375px부터 데스크톱까지 상세 페이지에 가로 스크롤이 없다.

## Assumptions

- **Tier**: C-READ-2는 Tier A(공통 필수). 상세에 붙는 댓글·태그·좋아요·조회수(Tier B)와 팔로우·알림·신고·숨김(Tier C)은 각 기능 명세가 규칙을 정하고, 이 명세는 화면에 붙는 자리와 표시 조건만 정한다.
- **결정에서 가져온 사항**: 글 주소는 번호 기반(01 Q4 제안, 05 §8), 권한 없음은 404·미리보기까지 동일(결정 기록 2026-10-02), 닉네임 변경 후 상세·댓글에 `닉네임 @블로그주소` 함께 표시(결정 기록 2026-10-02), 40 문서 결정(R-3 블로그 불일치 301, R-4·R-5 작성자의 임시글·수정 중 글, R-6 표시 날짜, R-9 캐시, 2026-10-03), 조회 기록은 31 W-3·W-4를 따름(2026-10-06).
- **문서 상태**: docs/40-post-detail.md는 "초안 (항목 확인 중)"이다. 열린 항목 중 관리자 조회 제외만 FR-021에 표시했고, 조회 기록 기능을 외부 파일로 두는 요청은 브라우저 보안 정책(헌법 IV)상 필수라 FR-023으로 확정했다.
- **응답 코드 기준**: 42 문서(401 로그인 필요 / 403 계정 상태만 / 404 없음·볼 수 없음·남의 것 / 400 규칙 위반 / 409 상태 충돌)를 따른다. 자기 글 좋아요는 42 P-9의 400을 따르며, 30 좋아요 문서의 403과의 차이는 좋아요 명세에서 맞춘다.
- **개인 확장**: 제목 위 카테고리 경로, 본문 아래 관련 글·이전/다음 글, 오른쪽 사이드바(나민서), 코드 복사 버튼(김민서), 글 주인의 남의 댓글 삭제는 개인 확장이다.
- **스크립트 없는 독자**: 조회 수에 세지 않는다(31 W-4의 결과). 세야 한다면 서버 기록 방식은 개인 확장이다.
