# Feature Specification: 탐색에 시리즈 탭

**Feature Branch**: `104-explore-series` | **Created**: 2026-10-16 | **Status**: Implemented (blog 1.61.0)

**Scope**: **강성찬 개인 확장**.

## 바꾸기 전(086)
- 탐색에는 [추천]·[트렌딩] 탭만 있었다. 시리즈는 각 블로그의 시리즈 화면에서만 볼 수 있었다.

## 결정
- 탐색에 [시리즈] 탭(`/explore?tab=series`)을 더한다. 시리즈 기능 스위치가 꺼져 있으면 탭도 없다.
- 모든 블로그의 시리즈 중 공용 목록 조건을 통과한 글이 1편 이상인 것만 보인다. 카드에 시리즈 이름, 주인 아이디, 공개 글 수.
- 정렬은 태그 모아 보기와 같은 [인기순]·[최근순]. 인기순 = 좋아요 합 → 글 수 → 최근 글, 최근순 = 최근에 글이 공개된 순. 기본은 인기순.
- 앞 60개만 보인다. 시리즈가 많아지면 더 보기를 붙인다.
- DB 바뀜 없음.

## Success Criteria
- 통합 테스트(ExploreIT): 시리즈 탭에 공개 글이 있는 시리즈만 보이고, 비공개 글만 있는 시리즈는 안 보이며, 정렬이 바뀐다.
