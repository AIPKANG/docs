# Quickstart: 이미지 업로드 (008)
1. `./gradlew test --tests '*Image*' --tests '*Gif*' --tests '*PostImage*'`.
2. 로컬: 편집 화면에 사진 붙여넣기 → `![](http://localhost:9000/blog-images/images/…webp)` 삽입, 저장소에 `…_thumb.webp`도 있음. 발행 → 카드 썸네일이 `_thumb`. GIF를 넣고 발행 → 상세에서 ▶ 누르면 재생.
3. 개발자 도구 Offline → 사진 넣기 → `local:` 표시 → Online → 진짜 주소로 바뀜.
