# Feature Specification: 글 카드 한 모양

**Feature Branch**: `088-card-unify` | **Created**: 2026-10-14 | **Status**: Implemented

**Scope**: **강성찬 개인 확장** (10-14 chan "카드는 이런 형식으로 통일하자, 지금 카드 모양이 다 달라", 이어서 지금 카드 캡처와 "이걸로 통일할까? 너가 확인해줘" → 지금 카드 구조로 통일, 사진 자리만 고침).

## 원인
- 홈·미션·내 글·시리즈(`.home-cards`)는 사진이 있는 글만 사진을 왼쪽에 둔 가로 카드가 되어, 같은 목록 안에서도 카드 모양이 달랐다.
- 하트가 좋아요 0개여도 빨간 꽉 찬 하트였다. 카드 목록은 내가 좋아요했는지 모른다.

## 결정(모든 목록 같은 카드)
위에서부터: 사진(글에 있을 때만, 맨 위, 카드 폭 16:10) → 머리 줄(아바타·아이디, 오른쪽에 첫 태그) → 굵은 제목(2줄 자리) → 요약 3줄 → 맨 아래 ♡ 좋아요 · 💬 댓글, 오른쪽 날짜.
- 사진을 왼쪽에 두는 가로 카드는 없앤다. 홈은 오른쪽 칸이 있어 넓은 화면에서 3칸.
- 아이디는 줄이지 않는다(머리 줄 전체보다 긴 30자 아이디만 …). 칸이 모자라면 태그가 먼저 줄어든다.
- 사진 없는 카드(10-14 chan "사진 들어간 카드 크기에 맞춰서 글씨 카드 크기 키워 주는 형식으로"): 빈 사진 칸은 두지 않는다. 같은 줄에 사진 카드가 있으면 그 높이만큼 카드가 늘어나고, 늘어난 자리는 요약 줄 수를 늘려 채운다(남는 높이에 맞는 줄 수, 최소 3줄). 요약이 짧은 글은 아래가 비는 게 정상. 좋아요·댓글·날짜 줄은 늘 카드 맨 아래.
- 줄 판단은 목록 전체가 아니라 "같은 줄"(`js/post/card-rows.js`가 카드 위치로 줄을 묶어 `.row-thumb`). 폭이 바뀌거나 무한 스크롤로 카드가 붙으면 다시 계산. 한 줄에 카드 하나(휴대폰)는 해당 없음. 스크립트가 없으면 요약 3줄 그대로.
- 좋아요 숫자와 댓글 숫자는 같은 굵기.
- 하트는 기본 회색 빈 하트(♡). 탐색에는 지금 "추천" 칩이 없다(086에서 목록 전체가 추천이라 뺐다).

## 적용 범위
공용 카드 조각(fragments/post-card)과 스크립트 카드(list-more.js)를 쓰는 홈·피드·탐색 [추천]/[트렌딩]·검색·태그·블로그 글 목록과 고정 글·시리즈·내 글 관리·미션 오늘 글·글 아래 "관심 있을 만한 글". 미션의 예전 카드(공용 카드가 없는 글)도 하트만 같게.

## Success Criteria
- 375·760·1000·1280px 헤드리스 Chrome 측정: 같은 줄 카드의 높이가 같고 반응 줄이 맨 아래, 보통 길이 아이디는 잘리지 않음.
- 사진 카드가 있는 줄의 사진 없는 카드는 요약이 3줄보다 길게 보이고(남는 높이만큼), 사진 없는 줄은 3줄. `frontend/src/test/js/card-rows.test.mjs`.
- 전체 테스트 통과.
